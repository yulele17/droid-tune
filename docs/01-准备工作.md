# 01 · 准备工作

## 1. 装一份能用的 adb

下载官方 platform-tools：
<https://developer.android.com/tools/releases/platform-tools>

解压到任意位置，把目录加入 PATH，验证：

```bash
adb version
# Android Debug Bridge version 1.0.41
```

### ⚠️ 不要用 adbutils / python-adb 自带的 adb.exe 代替

这是个纯浪费时间的坑。它们的 `adb.exe` 只是单个exe，
而官方 adb 还需要同目录的两个 DLL：

```
adb.exe
AdbWinApi.dll        ← 少这个就跑不起来
AdbWinUsbApi.dll     ← 少这个也跑不起来
```

症状极具迷惑性：**双击或命令行执行，完全没有任何输出，退出码 127。**
不会报"缺少 XX.dll"，什么提示都没有，你只会得到一个空的输出和一个看不懂的错误码。

所以：本机不需要 Python 的包管理器帮忙，直接用官方 platform-tools。

## 2. 手机端开三个开关

| # | 开关 | 位置 | 不开的后果 |
|---|---|---|---|
| 1 | 开发者选项 | 设置 → 关于手机 → 连点「版本号」7 下 | 后面两个都找不到 |
| 2 | USB 调试 | 开发者选项页内 | adb 完全连不上 |
| 3 | **USB 调试（安全设置）** | 开发者选项页内，往下翻 | **能看到/能读，但点不动、改不了设置** |

**第 3 个是最多人漏的**，它和「USB 调试」是两个独立开关，名字必须完整包含「（安全设置）」四个字。

打开时注意事项：

- 会弹风险提示，**要等倒计时结束**才能点「确定」。倒计时没走完就点，开关会弹回关闭状态。
- 前提条件：手机插了 SIM 卡，且登录了厂商账号。

### 打开后依然被系统拒绝 → 重启手机

这是本项目实测确认过的现象（在 HyperOS 上反复出现）：
开关显示绿色已开，adb 能连能读，但任何需要"点击/修改设置"的操作都被系统拒绝。

**解法：重启手机。** 重启后再确认：

1. 开发者选项里 **USB 调试** + **USB 调试（安全设置）** 是否都还开着（少数机型重启会掉）；
2. 重新插数据线，手机若弹「允许 USB 调试」→ 勾「始终允许」→ 确定；
3. 手机保持**解锁亮屏**。

## 3. 物理连接

- 用**能传数据**的数据线，别用只有充电功能的那种。
- 连上后手机若弹「充电 / 传输文件 / 传输照片」，选「传输文件」即可。
- **先关掉电脑上的手机助手、投屏软件**（厂商助手、scrcpy 等），它们会抢占 adb 连接，
  表现为跑着跑着突然断开。

## 4. 验证

```bash
python -m tune devices
1a43****      可用  Redmi Note 13 Pro  OS3.0.306.0.WNRCNXM
```

看到「可用」就齐活了。若显示「未授权」，去手机解锁点允许；
若显示「离线」，拔插重试。
